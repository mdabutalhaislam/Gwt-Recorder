# GWT Recorder

Screen recorder and video editor for Windows.

## Download

**[Download GWT Recorder for Windows](https://github.com/mdabutalhaislam/Gwt-Recorder/releases/latest)**: open the latest release and download `GWT-Recorder-Setup-<version>.exe`.

## Install

1. Run the downloaded `GWT-Recorder-Setup-….exe`.
2. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
3. Finish the setup and start GWT Recorder from the desktop shortcut.

Requirements: Windows 10 or 11 (64-bit).

## Pro

The free version adds a watermark and exports up to 720p. Get a Pro key at
[gamingwithtalha.com/store](https://gamingwithtalha.com/store) and enter it with **Activate Pro** in the app.
